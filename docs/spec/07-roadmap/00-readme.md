# Roadmap & Standards (Phase 5)

> **Phase 5 Overview**  
> This directory contains the operational plan for the 36-hour hackathon, including exactly what gets built when, how we write the code, and how we present the final product to the judges.

## Directory Structure

### Execution Roadmap (`/07-roadmap/`)
- `00-readme.md`: This file.
- `01-sprint-backlog.md`: The prioritized list of MVP features to build, and the features we are explicitly ignoring to save time.
- `02-hackathon-hour-by-hour.md`: The 36-hour timeline divided into checkpoints.
- `03-presentation-script.md`: The minute-by-minute script for the final demo, mapped to the E2E scenarios.

### Standards (`/08-standards/`)
- `00-coding-guidelines.md`: Python and JavaScript rules to ensure the codebase looks unified even when written by 4 different people at 3 AM.
- `01-git-workflow.md`: Branching strategy designed for extreme speed without losing code.
- `02-ui-ux-design-system.md`: The color palette, typography, and component library (Material UI / Tailwind) chosen for maximum visual impact with minimum CSS writing.

### Final Tracker (`/09-project-tracker/`)
- `00-master-checklist.md`: The final "Launch Day" checklist to ensure all ports are open, databases are seeded, and APIs are mocked before the judges walk over.
